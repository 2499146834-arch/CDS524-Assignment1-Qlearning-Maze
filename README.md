# CDS524 Assignment 1 — Q-Learning Maze Solver

A Q-Learning reinforcement learning agent that learns to navigate perfect mazes generated by Prim's algorithm. Features headless training, comprehensive experiment analysis, and interactive Pygame visualization.

## Demo Video

[Watch the demo on YouTube](https://youtu.be/rnaTBh07MHY)

## Quick Start

```bash
pip install numpy pygame matplotlib pandas
python run_demo.py        # Interactive Pygame visualization
jupyter notebook CDS524_Assignment1_Improved.ipynb  # Full experiments
```

Or double-click `run_demo.bat` on Windows.

## Bugs Found & Fixed

| Bug | Impact | Fix |
|-----|--------|-----|
| Prim maze generation | ~40% cells isolated, goal unreachable → 0% success | Frontier-based algorithm |
| Double-counted goal reward | +200 instead of +100 → distorted Q-values | Single reward calculation |
| Deterministic tie-breaking | `np.argmax` always picks first → directional bias | Random tie-breaking |

## Improvements

| Improvement | Original | This Work |
|-------------|----------|-----------|
| Q-table init | All zeros | Optimistic init = 50 |
| Epsilon decay | Linear 0.0008/step (bottoms out in 5 eps) | Exponential 0.997/ep + convergence gate |
| Training / Viz | Coupled with Pygame | Decoupled headless training |
| Experiment analysis | None | Convergence plots / hyperparameter search |
| Code structure | Single notebook | 5 modular `.py` files |

## Results (10×10 Perfect Maze)

| Metric | Original | Improved |
|--------|----------|----------|
| Maze connectivity | 62% | **100%** |
| Goal reachable | No | **Yes** |
| Training success rate | 0% | **62.5%** |
| Eval success rate (ε=0) | 0% | **51.5%** |
| First successful episode | Never | **Episode 2** |

The ~55% evaluation ceiling reflects the fundamental challenge of sparse-reward Q-learning on perfect mazes where only a single correct path exists. See the report for detailed analysis.
